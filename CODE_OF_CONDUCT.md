# Code of Conduct

## Our standard

BoardMedic is intended to be a technical, collaborative engineering project.

Contributors are expected to:

- communicate respectfully and professionally;
- critique technical ideas without attacking people;
- document safety concerns clearly;
- avoid knowingly publishing credentials, private diagnostic data or unsafe destructive instructions as if they were safe defaults;
- welcome corrections when evidence changes a diagnosis;
- keep discussions focused on reproducible engineering evidence.

Harassment, discrimination, threats, doxxing, deliberate sabotage and abusive conduct are not acceptable.

## Scope

This applies to repository issues, pull requests, discussions, reviews and other project-managed spaces.

## Enforcement

Report serious conduct concerns privately to the repository owner. Maintainers may edit, hide or remove content and restrict participation when necessary to keep the project safe and constructive.
